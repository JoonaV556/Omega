# Omega

Roguelite 2D shooter powered by Godot 4 game engine.

## Description

Planned features:
- Procedural level-generation
- Shooter mechanics
- Dynamic NPC behavior (Inspired by the *A-Life* -system from S.T.A.L.K.E.R games)
- Roguelite mechanics
- Story / Campaign
- Horror elements

Playable alpha version is on track to be released during the summer of 2026.  

Gameplay-related source code can be found in **/Code/** folder

Due to licensing reasons, asset dependencies such as image- and audio files are not publicly available in the main repository, but instead in private submodules.  

### Dependencies

Godot Editor 4.4
